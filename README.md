# 飞书妙记同步插件

一个面向 Obsidian 的飞书妙记同步工具，可将个人飞书账号中的会议内容自动整理并保存到本地知识库。

当前版本：`v0.9.1`  
运行平台：`macOS 桌面端`

## 主要功能

- 支持手动同步与定时同步飞书妙记
- 同步飞书智能纪要、AI 总结和完整逐字稿
- 支持保存图片、画板、待办、智能章节、关键决策和金句
- 将飞书图片转换为 Obsidian 本地附件，避免链接失效
- 支持按年、月或周整理会议纪要
- 自动识别已经同步的妙记，避免重复生成
- 自动补全正文不完整的历史笔记
- 内置术语校准、内容清洗和结构校验
- 同步异常时阻止写入，避免产生空白或不完整的笔记
- 支持检查并修复飞书授权及运行环境

## 环境要求

使用前请确保本机已安装：

- macOS
- Obsidian 1.4.0 或更高版本
- Node.js 16 或更高版本
- Python 3
- lark-cli

> 该插件仅支持 Obsidian 桌面端，暂不支持手机端。

## 安装方法

### 1. 安装 lark-cli

打开 macOS“终端”，执行：

```bash
npx @larksuite/cli@latest install
首次使用还需要执行：
lark-cli config init --new
按照终端和浏览器提示，使用自己的飞书账号完成授权。
2. 安装 Obsidian 插件
1. 下载并解压本仓库中的 ZIP 安装包。
2. 完全退出 Obsidian。
3. 双击解压目录中的 安装.command。
4. 按照提示选择自己的 Obsidian Vault 文件夹。
5. 重新打开 Obsidian。
6. 进入“设置 → 第三方插件”，启用“飞书妙记同步”。
如果 macOS 阻止脚本运行，请右键 安装.command，然后选择“打开”。
3. 检查授权
1. 打开 Obsidian 插件设置。
2. 进入“飞书妙记同步”。
3. 点击“检查并修复”。
4. 根据提示完成本人飞书账号授权。
5. 检查通过后，点击“同步一次”进行测试。
默认设置
- 会议笔记目录：FeishuMinutes/
- 附件目录：01-会议纪要/FeishuMinutes/assets/
- 自动同步间隔：30 分钟
- 默认回看范围：最近 7 天
- 目录分类：默认不分类，可切换为按年、按月或按周
以上配置均可在 Obsidian 的插件设置页面中修改。
更新插件
收到新版本安装包后：
1. 完全退出 Obsidian。
2. 解压新版安装包。
3. 双击新版 安装.command。
4. 选择之前安装插件的同一个 Obsidian Vault。
5. 安装脚本会自动备份旧版本，并保留个人设置和同步记录。
6. 更新完成后重新打开 Obsidian。
数据与隐私
安装包不包含任何用户的：
- 飞书登录凭证
- API Key
- 会议 Token
- 同步历史
- Obsidian 个人配置
- 本地文件路径
每位使用者都需要使用自己的飞书账号完成授权。相关凭证保存在使用者本机，请勿分享给他人。
注意事项
本插件通过 lark-cli 获取本人有权访问的飞书妙记内容，请遵守所在组织的数据安全、信息保密及权限管理要求，不要同步或传播无权处理的会议内容。
